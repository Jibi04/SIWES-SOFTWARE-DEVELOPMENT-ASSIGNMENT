### STUDENT FILE SYSTEM
This program creates new student data, updates and delete's student data, it uses .txt files for data persistence.

How to run:
on Windows::
 python -m Assignment-15-Files.student_file_system
on Linux::
  python3 -m Assignment-15-Files.student_file_system
