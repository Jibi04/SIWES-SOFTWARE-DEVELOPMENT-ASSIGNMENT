### Employee Payroll
A simple CLI-based employee payroll calculator built with Python.

The application allows users to give their base-salary, bonus, tax percentages. The gross salary and net salary are computed.

#### Features
basic input validation

#### How it works
The application Accepts user input and calculates gross and net salary.

#### Requirement
Python 3.9+
No external packages are required beyond the project's own modules.

#### Running the Application
Clone or download the project then run;
python -m Assignment-14-Payroll.payroll

Follow the prompts to compute your net salary.

#### Example
Firstname: James
Last Name: Barden
Base Salary: 1000000
Tax Percentage(%): 2
Bonus (%) [if any]: 3

Employee ID: c36d6f67-d3b6-4f2b-9caf-96216982896c
Full Name: James Barden
Bonus: $3.0
Tax: $20600.0
Base Salary: $1000000
Gross Salary: $1030000.0
****************************************************
NET SALARY: 1009400.0
****************************************************
